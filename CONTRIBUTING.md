# Guía de Contribución

¡Gracias por contribuir a MiAppMovil!

## Pautas de desarrollo
1. Utilizar TypeScript y verificar tipos antes de enviar cambios (`npx tsc --noEmit`).
2. Seguir las convenciones de Expo y componentes funcionales con React Hooks.
3. Mantener los componentes en sus carpetas respectivas (`src/screens`, `src/components`).
